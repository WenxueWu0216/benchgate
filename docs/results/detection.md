# Gate detection / false-alarm results

Generated by `python -m benchgate.sim.detection` (2.0 min). Gate: one-sided Mann-Whitney U on per-run p50 and p99, Holm-corrected at α=0.01, plus a 95% BCa bootstrap CI that must exclude 0 and a point estimate ≥ 1%. Rates are fractions of comparisons whose verdict was REGRESSION, with Wilson 95% intervals.
