# Change-point detection over commit history

Generated by `python -m benchgate.sim.history` (200 histories per cell, 120 commits each, 10 runs x 150 iterations per commit, each commit on one of 8 nodes with a per-node offset of sd 0.3% (tuned) / 1% (cloud)). Detection = a flag within [onset-3, onset+15] (creep: through the end of the creep + 15). False flags are flags anywhere else. Delay is in commits from onset to the first flag (for PELT, which is offline, it is the localisation error).

`pairwise-paired` is the merge gate (parent and commit interleaved on one node); `pairwise-unpaired` reuses the parent's stored runs from whichever node it ran on. PELT and CUSUM run on the stored per-commit series, which does include node offsets.
